I want to write a Python script that receives data about home runs in 2024 as input, both regular and postseason.

The script will group homeruns by player, chronologically ascending.

From there, a window function will look at each group of 2 home runs, each group of 3 home runs, .... up to 5 or 6? I don't know. Maybe up to 20? It would be crazy if someone hit like 10 straight homers into the same above-ground swimming pool area.

Each group of N home runs will be considered a set to feed into the smallest-circle problem.

The output of the function will be a (probably) CSV file that contains all the groups of N home runs and the diameter D of the smallest enclosing circle.
I want to plot N against D to look for interesting outliers - high N, low D would be a crazy outcome. Low N, very low D is hoped for. Very high N, reasonably low D would be cool.

The CSV file should also include the link to the video of each home run in question, so that a group of 3 nearly-identical homers (for example) can be viewed easily.

I probably want to filter out large values of D - 50 feet? 100 feet? Don't care about the many results where 2 homers could be enclosed be a circle with a 300 foot diameter, for example. Not interesting.

After plotting N against D, I can decide what to do next. Is this interesting at all? If yes, convert the data to JSON, and build a silly web app that visualizes it/lets people explore the data. The data would just be hosted along with the web app, and loaded directly in to the JS modules that build the React app.


Challenges:
- Implenting Welzl's algorithm for the least covering circle
- Plotting the results
- Visualizing a single result on a baseball diamond
